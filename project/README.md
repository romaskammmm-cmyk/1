# 📦 Результат работы команды

Сюда воркеры складывают всё, что делают, — строго по путям `outputs` из своих задач.

- Каждый файл «принадлежит» задаче, которая его создала. Чужие файлы не трогать.
- Финальный отчёт координатора: `project/REPORT.md` (что сделано, структура, как запускать/использовать).
