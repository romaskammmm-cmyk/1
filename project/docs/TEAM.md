# КОМАНДА — «Десять звеньев»
Все звенья работают в одном чате (Arena.ai Agent Mode), но общаются по протоколу репозитория: коммиты с префиксом `[<id>]`, задачи в `tasks/`, регистрация в `agents/registry/`.

| ID | Позывной | Мандат | Неприкосновенная зона |
|---|---|---|---|
| `dir-01` | Директор | видение, финальные решения в спорах, приёмка | `project/docs/GDD.md` |
| `narr-02` | Сценарист | сюжетная библия, записки, PA-тексты, финалы | `project/docs/STORY_BIBLE.md` |
| `lev-03` | Архитектор | планировки, блокинг залов, пейсинг уровней | `project/docs/CHAPTERS.md`, `scripts/…/museum_builder.gd` |
| `art-04` | Таксидермист (художник) | текстуры, материалы, свет, 2D-арт | `assets_gen/`, `art/` |
| `code-05` | Механик | контроллеры, ИИ образцов, взаимодействия | `scripts/gameplay/` |
| `audio-06` | Акустика | синтез звука, микс, эмбиент | `assets_gen/audio_gen.py`, `assets/audio/` |
| `ux-07` | Хранитель интерфейса | меню, HUD, карточка вида, локализация, настройки | `scripts/ui/`, `scenes/ui/` |
| `qa-08` | Натуралист (QA) | smoke-тесты, скриншот-сессии, чек-листы, баланс | `tests/`, `project/docs/QA_LOG.md` |
| `build-09` | Сборщик | экспорт Windows EXE, скрипты сборки, релизы | `tools/`, `builds/` |
| `lore-10` | Архивариус | фактчек лора (Ламарк/Линней/Дарвин), связность, этикетки | `project/docs/LORE_FACTS.md` |

## Правило двух ключей
Любое изменение лора/пейсинга/механики: инициирует один — утверждает `dir-01`, фактчит `lore-10`, в жертву приносится один вкусный вариант (мы всегда хороним одну хорошую идею, чтобы две другие жили).

Похоронена идея: реалистичная вода с отражениями (гл. 2 станет стилизованной, «чернильной»).
