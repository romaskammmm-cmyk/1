🤖 Мульти-агентный пульт

Запуск команды агентов, работающих сообща через GitHub-репозиторий

1. Данные для запуска

Нет токена? Создайте: github.com → аватар → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic), галочка repo. Токен никуда не отправляется — сообщения генерируются локально в этом файле.

2. Сообщение для КООРДИНАТОРА отдельный новый чат

⛔ Безопасность: в каждом сообщении есть ваш токен. После окончания работы отзовите его: github.com → Settings → Personal access tokens → Delete. Репозиторий публичный — секреты в него не класть.

📖 Как запустить команду (5 минут)

  1. Во вкладке 🚀 Запуск вставьте токен, опишите цель проекта, выберите число воркеров и нажмите «Сгенерировать».
  2. Скопируйте сообщение координатора → откройте новый чат с агентом → вставьте → отправьте. Дождитесь ответа «готов».
  3. Для каждого воркера повторите: отдельный новый чат + его сообщение. Один агент = один чат, иначе они перемешаются.
  4. Наблюдайте во вкладке 📊 Статус (нужен обычный браузер с интернетом) или прямо на странице репозитория на GitHub.
  5. Координатор в конце напишет project/REPORT.md и сигнал comms/broadcast/DONE.md — работа окончена.
  6. Отзовите токен (Settings → Personal access tokens → Delete).

⚙️ Как это работает

  • Каждый агент живёт в своей песочнице, а репозиторий — их общая память и почта.
  • Координатор режет цель на задачи (tasks/queue/*.json), воркеры разбирают их по правилу «кто первым запушил — того и задача».
  • Общение — через файлы: comms/broadcast/ (всем) и comms/inbox/<агент>/ (лично). Задержка — минуты, это нормально.
  • Каждый агент шлёт heartbeat в agents/registry/ — видно, кто жив и чем занят.
  • Все правила — в файле agents/PROTOCOL.md в репозитории. Это «закон», которому следует каждый агент.

❓ Частые вопросы

  • Сколько воркеров? 2–4. Больше — толкутся и конфликтуют в git.
  • Агенты видят друг друга в реальном времени? Нет. Только через репозиторий с задержкой в минуты. Для параллельной работы по файлам этого хватает.
  • Git-конфликты? Протокол их почти исключает: каждый пишет в свои файлы, задачи разбираются правилом first-push-wins.
  • Агент завис? Напишите ему в его чат «сделай git pull --rebase, проверь inbox и продолжай». Если молчит дольше 20 минут — координатор вернёт его задачу в очередь сам.
  • Хочу остановить всё? Попросите координатора в его чате завершить работу (он напишет DONE.md), либо просто закройте чаты.
  • Лимит воркспейса 128 МБ? Агенты пушат готовое в репозиторий и чистят локальные копии — репозиторий работает как внешний диск.

📊 Статус команды
