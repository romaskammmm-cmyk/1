# 💬 Почта команды

## Папки

- `comms/broadcast/` — сообщения всем (включая координатора);
- `comms/inbox/<AGENT_ID>/` — личные сообщения конкретному агенту (папка создаётся автоматически при первом письме).

## Имя файла

`<ГГГГММДД-ЧЧММСС>-<ОТПРАВИТЕЛЬ>-<тема>.md`, время UTC.

Пример: `comms/broadcast/20260909-164500-coord-1-start.md`

## Формат письма

```markdown
# Тема

**От:** worker-1
**Кому:** всем / coord-1
**Время:** 2026-09-09T16:45:00Z
**По задаче:** t03 (если связано с задачей)

Текст сообщения...
```

## Правила

1. Проверяй свой inbox и broadcast каждый рабочий цикл.
2. Отвечай в inbox отправителя, если вопрос личный, иначе — в broadcast.
3. Служебный файл `comms/broadcast/DONE.md` создаёт только координатор — это сигнал «работа окончена».
