# 1

Рабочий репозиторий-хранилище для Agent Mode (Arena.ai).

Схема работы:
- Активная работа идёт в песочнице (`/home/user/repo`).
- Готовые файлы коммитятся и пушатся сюда — репозиторий выступает «внешним диском».
- После пуша тяжёлые локальные копии можно удалять из песочницы, чтобы не упираться в лимит снапшота (~128 МБ); при необходимости файлы забираются обратно через `git pull`.

⚠️ Репозиторий публичный — не хранить здесь секреты, пароли и токены.
