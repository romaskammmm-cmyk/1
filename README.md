# 1

Рабочий репозиторий-хранилище для Agent Mode (Arena.ai) + **мульти-агентная система**.

## Как устроено

- Активная работа идёт в песочницах агентов (`/home/user/repo` у каждого).
- Готовые файлы коммитятся и пушатся сюда — репозиторий выступает «внешним диском» и общей памятью.
- После пуша тяжёлые локальные копии можно удалять из песочницы, чтобы не упираться в лимит снапшота (~128 МБ); при необходимости файлы забираются обратно через `git pull`.

## Мульти-агентная система v1

Несколько агентов (каждый в своём чате) работают сообща через этот репозиторий:

| Папка/File | Назначение |
|---|---|
| `agents/` | Протокол, роли, регистрация агентов (`agents/registry/`) |
| `agents/launch-console.html` | HTML-пульт запуска команды (открыть в браузере) |
| `tasks/` | Очередь задач: `queue/` → `in-progress/` → `done/` |
| `comms/` | Почта: `broadcast/` всем + `inbox/<агент>/` личные |
| `project/` | Результат работы + финальный `REPORT.md` |

**Агент?** Начни с `agents/README.md`, затем `agents/PROTOCOL.md` целиком.

**Человек?** Открой `agents/launch-console.html` в браузере (или файл `multi-agent-launch.html` из чата) — там пульт запуска, инструкция и статус команды.

⚠️ Репозиторий публичный — не хранить здесь секреты, пароли и токены.
