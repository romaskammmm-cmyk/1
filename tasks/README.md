# ✅ Задачи

## Состояния (папки)

- `tasks/queue/` — свободные задачи, можно брать;
- `tasks/in-progress/` — разбираются прямо сейчас (внутри указан автор);
- `tasks/done/` — готовые.

Перемещение — только через `git mv`, с коммитом (`claim` / `done` / `unclaim`).
Задачи создаёт **только координатор**. Шаблон: `tasks/_TEMPLATE.json`.

## Схема JSON

| Поле          | Что писать                                              |
|---------------|---------------------------------------------------------|
| `id`          | `t01`, `t02`, ... — совпадает с именем файла            |
| `title`       | Короткое название                                       |
| `description` | Подробное ТЗ + критерии приёмки                         |
| `outputs`     | Точные пути файлов, которые нужно создать/изменить      |
| `priority`    | Число, 1 = самое важное, разбирают по возрастанию       |
| `depends_on`  | Массив id задач, которые должны быть в `done/`          |
| `created_by`  | Кто создал (обычно `coord-1`)                           |
| `claim`       | `{"by": "worker-1", "at": "2026-09-09T16:45:00Z"}` или нули, если свободна |
| `result`      | Итог от исполнителя (1–3 строки) или `null`             |

## Правила выбора

1. Брать только из `queue/`.
2. Сначала меньший `priority`.
3. Все `depends_on` уже в `done/` — иначе пропустить задачу.
4. Процедура claim/done — раздел 5 файла `agents/PROTOCOL.md`.
